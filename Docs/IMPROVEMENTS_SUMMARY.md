## 1. Fallback на "Другое" вместо nil
**Статус:** ✅ Реализовано

При импорте, если категория не определена гессером или правилами, автоматически подставляется "Другое" (если она существует в базе).

**Где:** `CategoryRuleEngine.swift`

```swift
// Fallback на "Другое" если категория не найдена
if existingCategories.contains(where: { $0.name == "Другое" }) {
    return "Другое"
}
```

## 5. Умная замена при переименовании (#7)
**Статус:** ✅ УЖЕ БЫЛО РЕАЛИЗОВАНО

При переименовании категории в `CategoryDetailView` автоматически обновляются:
- Все транзакции с этой категорией
- Все legacy expenses
- Все правила категоризации

**Где:** `TransactionCategorySync.renameCategory()`

---

## Как это работает вместе:

### Импорт транзакции:
1. Проверяются **пользовательские правила** (высокий приоритет)
2. Если не найдено → проверяются **встроенные правила** (если включены)
3. Если не найдено → проверяется существование угаданной категории
4. Если категории нет → ставится "Другое"
5. Если "Другое" нет → `nil`

### Управление категориями:
- Переименование категории → автоматически обновляются все транзакции и правила
- Удаление категории → можно выбрать категорию для замены

### Настройка встроенных правил:
- Открыть: Настройки → Встроенные правила
- Отключить ненужные (например, COFFEE → Еда)
- Включить нужные
- Настройки сохраняются между запусками
