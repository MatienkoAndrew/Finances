# Как протестировать изменения

## Сценарий 1: Категория "Кофе" удалена

1. **Подготовка:**
   - Откройте раздел "Категории"
   - Если есть категория "Кофе", удалите её
   - При удалении выберите категорию "Еда" для замены существующих транзакций

2. **Тест:**
   - Импортируйте Kaspi-документ с транзакциями из STARBUCKS или HIGHLANDS COFFEE
   - Проверьте новые транзакции

3. **Ожидаемый результат:**
   - ✅ Категория не должна быть "Кофе"
   - ✅ Категория должна быть пустой (без категории) или соответствовать вашему правилу

## Сценарий 2: Создание правила для переопределения

1. **Подготовка:**
   - Откройте раздел "Правила"
   - Создайте правило: паттерн "STARBUCKS", категория "Еда", высокий приоритет

2. **Тест:**
   - Импортируйте Kaspi-документ с транзакцией из STARBUCKS
   - Проверьте категорию

3. **Ожидаемый результат:**
   - ✅ Категория должна быть "Еда" (по правилу)
   - ✅ Даже если категория "Кофе" существует, применится правило

## Сценарий 3: Все категории на месте

1. **Подготовка:**
   - Убедитесь, что все системные категории существуют:
     - Кофе
     - Еда
     - Продукты
     - Транспорт
     - Подписки
     - и т.д.

2. **Тест:**
   - Импортируйте обычный Kaspi-документ

3. **Ожидаемый результат:**
   - ✅ Категории должны подставляться как обычно
   - ✅ Никаких изменений в поведении

## Отладка

Если что-то не работает, проверьте:

1. **Компиляция:** проект должен компилироваться без ошибок
2. **Query в TransactionsView:** убедитесь, что categories загружаются
3. **ExpenseCategoryGuesser:** можно добавить print-ы для отладки:

```swift
let guessedName = ExpenseCategoryGuesser.guessCategoryName(
    for: operationType,
    details: details
)
print("🔍 Guessed category: \(guessedName ?? "nil")")
print("📋 Existing categories: \(existingCategories.map { $0.name })")
```

## Дополнительно: Изменение логики угадывания

Если хотите, чтобы STARBUCKS всегда относился к "Еда" на уровне кода:

В `ExpenseCategoryGuesser.swift` строки 28-30:

```swift
// Было:
if text.contains("COFFEE") || text.contains("HIGHLANDS") || text.contains("STARBUCKS") {
    return "Кофе"
}

// Изменить на:
if text.contains("COFFEE") || text.contains("HIGHLANDS") || text.contains("STARBUCKS") {
    return "Еда"
}
```
