## 💡 Советы

### Быстрое перемещение

1. **Множественный выбор:** Удерживайте ⌘ и выбирайте несколько файлов
2. **Drag & Drop:** Перетаскивайте файлы в нужную группу
3. **Cut & Paste:** ⌘X для вырезания, ⌘V для вставки

### Поиск недостающих файлов

Некоторые файлы могут быть не в корне. Используйте:

```
⌘⇧O → введите название файла
```

Например:
- `ExpenseCategoryItem`
- `ExchangeRateEntry`
- `TrackedExchangeRate`
- `TransactionTag`
- `AccountsView`

## ⚠️ Важные замечания

1. **Не удаляйте файлы** — только перемещайте

3. **Сделайте коммит ДО начала** — чтобы можно было откатиться
4. **Проверьте компиляцию** — после перемещения (⌘B)
