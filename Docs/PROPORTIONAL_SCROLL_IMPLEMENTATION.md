# Реализация плавного пропорционального скролла графика

## Обзор

Реализован **плавный пропорциональный скролл графика аналитики**, аналогичный поведению в приложении "Здоровье" (Health) на iPhone.

## Что изменилось

### 1. **InteractiveBarChartView.swift**

Добавлена новая структура `ProportionalSwipeInfo` для передачи детальной информации о свайпе:

```swift
struct ProportionalSwipeInfo {
    let distance: CGFloat          // Дистанция свайпа в пикселях
    let velocity: CGFloat          // Скорость в пикселях/секунду
    let duration: TimeInterval     // Длительность жеста
    let direction: SwipeDirection  // Направление свайпа
    
    enum SwipeDirection {
        case forward   // Влево (вперёд во времени)
        case backward  // Вправо (назад во времени)
    }
    
    enum SwipeIntensity {
        case minimal  // < 50px или очень медленно
        case light    // 50-150px, медленная скорость
        case medium   // 150-250px, средняя скорость или быстро
        case strong   // > 250px, высокая скорость
    }
}
```

**Ключевые изменения в жесте:**

- Отслеживание времени начала свайпа для расчёта velocity
- Расчёт distance, velocity и duration при завершении свайпа
- Haptic feedback в зависимости от интенсивности (light/medium/rigid)
- Уменьшен минимальный порог с 36px до 20px для более чувствительного отклика

### 2. **AnalyticsView.swift**

Добавлены методы для обработки пропорционального скролла:

#### `handleProportionalSwipe(_ swipeInfo: ProportionalSwipeInfo)`

Основной метод обработки свайпа:
- Рассчитывает пропорциональный сдвиг в днях
- Проверяет граничные условия (нельзя уйти в будущее)
- Выбирает анимацию в зависимости от силы свайпа
- Обрабатывает предупреждающий haptic feedback при достижении границы будущего

#### `calculateProportionalOffset(for swipeInfo: ProportionalSwipeInfo) -> Double`

Рассчитывает величину сдвига в днях на основе параметров свайпа:

**Калибровочные коэффициенты:**
- Week: 80 (базовый коэффициент)
- Month: 100 (менее чувствительный)
- Year: 60 (более чувствительный)

**Множитель скорости:**
- > 2000 px/s: 3.0x
- > 1500 px/s: 2.5x
- > 1000 px/s: 2.0x
- > 500 px/s: 1.5x
- < 500 px/s: 1.0x

**Ограничения по масштабу:**
- Week: 1-14 дней (макс. 2 недели)
- Month: 2-60 дней (макс. 2 месяца)
- Year: 15-365 дней (макс. 1 год)

## Поведение

### Лёгкий короткий свайп (50-100px, медленно)
- Week: 1-2 дня
- Month: 2-4 дня
- Year: ~15-30 дней

### Средний свайп (150-200px, средняя скорость)
- Week: 3-5 дней
- Month: ~7-10 дней
- Year: ~60-90 дней

### Сильный быстрый свайп (>250px, высокая скорость)
- Week: до 14 дней (2 недели)
- Month: до 60 дней (2 месяца)
- Year: до 365 дней (1 год)

## Haptic Feedback

### При свайпе в режиме пролистывания:
- **Начало свайпа**: light (intensity: 0.5)
- **Завершение minimal/light**: light (intensity: 0.8)
- **Завершение medium**: medium
- **Завершение strong**: rigid (intensity: 1.0)

### При попытке свайпнуть в будущее:
- **Warning notification** (UINotificationFeedbackGenerator)

### При выборе бара:
- **Light** (intensity: 0.7) — при выборе нового бара

## Анимации

### В зависимости от силы свайпа:
- **Minimal/Light**: spring(response: 0.5, dampingFraction: 0.80)
- **Medium**: spring(response: 0.35, dampingFraction: 0.78)
- **Strong**: spring(response: 0.28, dampingFraction: 0.75)

### Bounce-эффект:
- Направление: -10/+10 пикселей
- Анимация вперёд: spring(response: 0.25, dampingFraction: 0.6)
- Анимация назад: spring(response: 0.4, dampingFraction: 0.75) с delay 0.08s

## Зоны взаимодействия

- **Верхняя зона (бары)**: Режим выбора (selection) — тап/свайп выбирает конкретный бар
- **Нижняя зона (подписи осей)**: Режим пролистывания (paging) — свайп скроллит график по времени

Высота нижней зоны: 26 пикселей

## Граничные условия

### Будущее:
- При попытке свайпнуть вперёд дальше текущей даты:
  - Вызывается warning haptic
  - Свайп не выполняется
  - Остаётся bounce-эффект для визуальной обратной связи

### Прошлое:
- Ограничений нет, можно листать бесконечно назад

## Формула расчёта сдвига

```swift
baseOffset = distance / calibrationCoefficient
velocityMultiplier = f(velocity) // 1.0 ... 3.0
rawOffset = baseOffset × velocityMultiplier
finalOffset = clamp(rawOffset, min, max) // Ограничения по масштабу
```

## Примеры использования

### Лёгкий свайп на 80px за 0.5s (velocity = 160 px/s):
```
Week scale:
  baseOffset = 80 / 80 = 1.0
  velocityMultiplier = 1.0
  finalOffset = 1.0 день
```

### Быстрый свайп на 250px за 0.15s (velocity = 1666 px/s):
```
Week scale:
  baseOffset = 250 / 80 = 3.125
  velocityMultiplier = 2.5
  rawOffset = 7.8 дней
  finalOffset = 7.8 дней (в пределах 1-14)
```

### Очень быстрый свайп на 300px за 0.1s (velocity = 3000 px/s):
```
Year scale:
  baseOffset = 300 / 60 = 5.0
  velocityMultiplier = 3.0
  rawOffset = 15.0 дней
  finalOffset = 15.0 дней (минимум для Year)
  
  Если расстояние больше:
  baseOffset = 500 / 60 = 8.33
  rawOffset = 25.0 дней
  finalOffset = 25.0 дней
```

## Тестирование

Для тестирования разных сценариев:

1. **Лёгкие свайпы** — медленно проводите пальцем на 50-100px
2. **Средние свайпы** — проводите со средней скоростью на 150-200px
3. **Сильные свайпы** — быстро проводите на большое расстояние
4. **Попытка уйти в будущее** — свайпните влево на текущей неделе/месяце
5. **Переключение масштабов** — проверьте поведение на Week/Month/Year

## Возможные улучшения

1. **Инерционный скролл** — продолжение движения после отпускания с замедлением
2. **Визуальный индикатор** — показывать "резиновую тягу" при попытке уйти в будущее
3. **Калибровка коэффициентов** — после тестирования можно подстроить точнее под реальное поведение Health
4. **Snap-эффект** — автоматическое выравнивание на границы недель/месяцев при небольших сдвигах
5. **История навигации** — кнопки "назад/вперёд" для возврата к предыдущим просмотренным периодам

## Совместимость

- **iOS 17.0+** (требуется для spring анимаций с новыми параметрами)
- **SwiftUI** (Charts framework)
- **Swift 5.9+**

## Заметки

- Все параметры калибровки (коэффициенты, множители, пороги) можно настраивать
- Haptic feedback можно отключить через Settings, если потребуется
- Анимации настроены на баланс между отзывчивостью и плавностью
